# Online Games

A modern browser game portal built with plain HTML, CSS, and JavaScript.

## Features
- Responsive game landing page inspired by a game portal layout
- Search and category filtering
- Featured section and all-game grid
- Built-in mini games:
  - Memory Match
  - Tic Tac Battle
  - Rock Paper Fire
  - Number Guess
  - Reaction Rush

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

### Example with Python
```bash
cd online-games
python3 -m http.server 8000
```

Then open: http://localhost:8000

## Notes
This project is an original game portal website. It does not include copyrighted assets or copied games from other publishers.
